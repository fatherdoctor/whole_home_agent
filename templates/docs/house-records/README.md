# House records (template)

Copy into `house/docs/house-records/`. Principle: `principles/house-records-and-equipment.md`.

## Cloud-drive folders (create once; the agent keeps their IDs in its own notes)
- 00 Inbox - drop anything here
- 01 Equipment / HVAC, Water and plumbing, Kitchen, Laundry, Garage, Irrigation, Electrical, Other
- 02 Plans, survey and foundation
- 03 Warranties, receipts and contracts
- 04 Service history
- 98 Needs <owner>

File names: `<Item> (<make model>) - <what the photo shows> - <YYYY-MM-DD>.<ext>`.

## Intake pass (each time, and on the owner's "uploaded")
1. List the inbox, following every page token; keep results whose parent is still the inbox.
2. Read each file; write or extend an inventory row (`inventory.md`); note secrets you saw and did NOT record.
3. Copy to the local mirror, then move and rename in the drive (copy, never move, files linked from elsewhere).
4. Guest-safety facts -> the manual's queue; schedules -> the maintenance calendar (with approval).
5. Add or re-size the follow-on rows (archive fetches, wiki pages, manual, reminders) in the same commit.
6. Report: what was filed, what could not be taken and why, the questions only the owner can answer.
