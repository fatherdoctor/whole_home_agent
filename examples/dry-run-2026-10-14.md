*A record from October 2026. The kit has fixed the gaps listed here since then, and the file lines it cites have
moved. Read it as history, not as the kit's current state.*

*Status: O4. One run of the dry run the backlog asked for: "a deliberately different stack (Pi, Matter, Apple Home, a
non-Claude agent) walks the kit from zero; every question or guess is a gap; fix or list them."*

sub-agents, memory directory or scheduler), started at `AGENTS.md` and followed every pointer for a fictional
household: a Raspberry Pi 5 on NVMe, a Connect ZBT-1 for Thread, Matter Wi-Fi plugs, Apple Home with a HomePod mini,
iPhones only, a child, a dog and a weekday dog walker. It walked Phase 0 and Phase 1 in full and planned five
Phase 2 items. The walk is `pi-matter-apple.md`. It also checked every backticked path in the kit and ran the
template tests.

**Result.** 40 gaps: 2 blockers, 24 major, 14 minor. Fixed in the same commit: 26; partly fixed: 7; open:
7. Both blockers are fixed: there was no way for an agent to reach the box (`install/agent-access.md` now), and
no Thread procedure (`adapters/radios/matter-thread.md` now). Paths: 3 of 383 broken (`push_guard.py`, now
`templates/guard/push_guard.py`; `IDLE.md` and `OUT-OF-BAND.md` in the tier-2 brief, open). Tests: 65 pass with
jinja2 installed (77 with the guard's cases); the documented `pip install` fails on systems that refuse a plain
pip, so the README now uses a virtual environment.
